# Security Policy

## Supported Versions

This is a new project and does not have any supported versions with security updates yet.

## Reporting a Vulnerability

Please report security vulnerabilities to security@example.com.

We will acknowledge receipt of your vulnerability report within 48 hours, and we will send you a more detailed response within 72 hours indicating the next steps in handling your report. After the initial reply to your report, the security team will endeavor to keep you informed of the progress towards a fix and full announcement, and may ask for additional information or guidance surrounding the reported vulnerability.
